🔧 Hardware

  • Controlador: ESP32
  • Habitaciones: 5 (Pines 26,27,19,22,23)
  • Motobomba: Relé Pin 32 (Inicia APAGADA)
  • Puerta: Servo Pin 18
  • Gas: MQ-2 Pin 35 (ADC)

📱 Conectividad

  • WiFi: [Tu Red WiFi]
  • Servidor: Puerto 80
  • Telegram: Multi-usuario
  • Usuario 1: [Chat ID 1]
  • Usuario 2: [Chat ID 2]

🚪 Control Puerta

  • Abrir: 90° → 180° (1s) → 90°
  • Cerrar: 90° → 0° (1s) → 90°
  • Neutral: 90° siempre
  • Estados: Cerrada/Abriendo/Abierta/Cerrando

⚠️ Seguridad Gas

  • Normal: >800 ADC (Aire limpio)
  • Alerta: 500-800 ADC (Gas detectado)
  • Crítico: <500 ADC (Emergencia)
  • Acción: Apagar todo + Cerrar puerta
